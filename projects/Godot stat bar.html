Godot stat bar

An augmented version of Godot's built-in progress bar, able to show change in value smoothly.

Implmentation

Godot already has 2 built-in progress bar nodes already, namely ProgressBar and TextureProgressBar. I chose to extend TextureProgressBar because it can be turned into a radial bar and be supplied a texture to draw on top of it.

I first set up a test user interface that only consists of the extended TextureProgressBar and a button that randomises the value of said progress bar.

Since the value property of the progress bar affects its fill, and that I want the change in value to be shown smoothly, I decided that a separate variable is needed to store the "actual" value set. This variable will be private by convention, and any changes to it will be made via functions.

Known bug(s)

When developing Ministry of Spinning I discovered that when reloading the scene containing the stat bar, the stat bar retains its previous current value. I have not yet identified its cause.

Future addition(s)

Right now the change in value is done by interpolating the current value to target value every frame, resulting in a big change initially and quickly resulting in small changes. I would like to add an option such that the change may be done by subtracting a fixed amount every frame for a more consistent change.
